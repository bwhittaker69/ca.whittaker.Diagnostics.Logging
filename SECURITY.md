# Security

Report suspected vulnerabilities using [GitHub private vulnerability reporting](https://github.com/bwhittaker69/ca.whittaker.Diagnostics.Logging/security/advisories/new). Do not include credentials or personal information in public issues.

Include the package version, impact, and a synthetic reproduction. There is no guaranteed response time. Support is currently limited to assessing reports against the latest published version.

Logging does not redact data. Applications control what they log, destination permissions, retention, and access.
